# Reproducibility Package

## Manuscript

**Authority Windows for Full Retention of Co-Moving Realizability Sets**

Authors:

- Guangqing Zhang
- Lei Zhang
- Ning Zhang (corresponding author)
- Chuanhui Huang
- Xiangdong Ni

This repository is the reproducibility package accompanying the manuscript submitted to *IEEE Transactions on Automatic Control*.

It contains deterministic MATLAB scripts, figure assets, and documentation for reproducing and verifying the numerical results reported in the manuscript.
